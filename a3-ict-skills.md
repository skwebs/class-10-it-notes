# Chapter 3: Information and Communication Technology (ICT) Skills

## 3.1 Introduction to ICT

**Information and Communication Technology (ICT)** refers to a diverse set of technological tools and resources used to communicate, create, disseminate, store, and manage information. ICT skills are essential in the modern world because they help individuals run businesses, access educational resources, and stay connected with family, friends, and the global community.

### Core Components of a Computer System

A computer system operates through the seamless integration of two fundamental components:

```
                  [ COMPUTER SYSTEM ]
                          |
         +----------------+----------------+
         |                                 |
   [ HARDWARE ]                      [ SOFTWARE ]
 (Physical, Tangible)             (Intangible, Code)
 e.g., CPU, Keyboard, Monitor     e.g., OS, Apps, Browsers
```

1. **Hardware**:
   * **Definition**: The physical, tangible parts of a computer system that we can see, touch, and handle.
   * **Key Examples**: Central Processing Unit (CPU), Keyboard, Monitor, Mouse, Printer, Hard Disk Drive, and Motherboard.
   * **Function**: Hardware acts as the machinery or physical vehicle that executes instructions and processes data.

2. **Software**:
   * **Definition**: The intangible set of programs, instructions, and code that tells the computer hardware exactly how to perform tasks. We cannot physically touch software.
   * **Key Examples**: Operating Systems (like Windows, Linux), Web Browsers (Chrome, Firefox), Office Suites (LibreOffice, MS Office), and games.
   * **Function**: Software provides the instructions and interface required to make the hardware functional and useful to the end-user.

### The Operating System (OS)
The **Operating System (OS)** is the most important software on any computer. It acts as an intermediary or bridge between the user and the computer hardware.
* **Initialization**: The OS starts running automatically as soon as the computer is switched on.
* **Functions**: It displays the desktop on the monitor, manages physical memory, schedules tasks, controls peripheral devices (keyboard, mouse, printer), and coordinates the execution of application software.
* **Examples**: 
  * **Ubuntu / Linux**: A free, open-source operating system.
  * **Microsoft Windows**: A widely used proprietary operating system developed by Microsoft.
  * **macOS**: Apple's proprietary operating system for Macintosh computers.

### Application Software
These are computer applications designed to perform specific, targeted tasks for the user. They run on top of the operating system.
* **Key Examples**:
  * **Web Browsers**: (e.g., Google Chrome, Mozilla Firefox) used to browse internet websites.
  * **Office Tools**: (e.g., LibreOffice Writer, MS Word, spreadsheets, presentations) used for academic writing and calculations.
  * **Games & Media Players**: Used for recreation and entertainment.

## 3.2 Basic Computer Operations

Operating a computer correctly ensures the safety of system files, preserves hardware life, and keeps user data secure.

### Starting a Computer (The Booting Process)

To start a computer, you must press the **Power Button** on the CPU cabinet. Once pressed, the computer undergoes a automatic startup process:

1. **BIOS (Basic Input/Output System) Execution**:
   * As soon as the system is powered on, a built-in, low-level program called **BIOS** runs automatically from the motherboard's ROM.
2. **POST (Power-On Self-Test)**:
   * The BIOS performs a hardware diagnostics check known as **POST**. This self-test verifies if all essential hardware devices (RAM, keyboard, hard drive, CPU fan, etc.) are connected, functional, and receiving power.
3. **OS Loading**:
   * If the self-test completes successfully without errors, the BIOS locates and loads the **Operating System (OS)** from the hard disk into the computer's primary memory (RAM). Once loaded, the user is presented with the login screen.

### Login and Logout (Access Control)

Securing your computer prevents unauthorized access and protects sensitive personal files from being viewed, altered, or stolen.

* **Login (Sign In)**:
  * Users protect their accounts using a unique **Login-ID** (username) and a secure **Password**.
  * When you input these credentials, the operating system verifies your identity, recognizes you as an authorized user, and loads your personalized desktop workspace, preferences, and applications.
* **Logout (Sign Out / Log Off)**:
  * Once you finish your work, you must log out or sign out of your account.
  * Logging out closes your active workspace session and locks the user interface, preventing other users from viewing your files, accessing your browser history, or tampering with your work while the computer remains turned on.

## 3.3 Keyboard Keys and Functions

The keyboard is the primary input device used to enter text, numbers, and commands into the computer. Standard computer keyboards are organized into distinct groups of keys based on their functions.

| Key Classification | Description and Purpose | Key Examples |
| :--- | :--- | :--- |
| **Function Keys** | Labeled from **F1 to F12**. These are programmable keys used to perform specific shortcuts or software-defined tasks. | **F1** (usually opens the Help window); **F5** (refreshes the browser or page). |
| **Control Keys** | Special keys designed to alter or modify the action of other keys. They perform custom commands based on when and where they are pressed. | **Control (CTRL)**, **SHIFT**, **ALT**, **SPACEBAR**, **CAPS LOCK**, and **TAB**. |
| **Enter (Return) Key** | Used to move the cursor to the beginning of a new line in document editors, send typed commands, or confirm dialog boxes. | **ENTER** or **RETURN**. |
| **Punctuation Keys** | Keys that represent standard punctuation marks used during text composition to make sentences readable. | Colon (**:**), Semicolon (**;**), Question Mark (**?**), Single Quotes (**' '**), and Double Quotes (**" "**). |
| **Windows Key** | A key with the Windows logo that opens the system's main Start menu instantly. | **Windows Key** (or super key in Linux). |
| **Navigation Keys** | Keys used to move the text cursor around documents, edit text, or scroll through web pages. | **Arrow Keys** (Up, Down, Left, Right), **HOME** (goes to line start), **END** (goes to line end), **PAGE UP**, and **PAGE DOWN**. |
| **Command Keys** | Keys used to execute editing operations, modify insert modes, or delete text characters. | **INSERT (INS)**, **DELETE (DEL)**, and **BACKSPACE**. |

### Detailed Editing Command Keys Difference
* **Backspace**: Deletes the character directly to the **left** of the cursor position.
* **Delete**: Deletes the character directly to the **right** of the cursor position.

## 3.4 Using the Mouse (Mouse Operations)

The mouse is a hand-held pointing device that detects two-dimensional motion relative to a flat surface. It allows users to interact with graphical user interface (GUI) elements on the screen.

```
       [ LEFT BUTTON ]          [ RIGHT BUTTON ]
       (Primary Click)          (Context Menu)
              \                      //
               +----------------------+
               |                      |
               |     [SCROLL WHEEL]   |
               |     (Document Scroll)|
               +----------------------+
```

1. **Roll Over or Hover**:
   * **Action**: Bringing the mouse pointer over a specific graphical item (like a file, folder, or link) on the screen without clicking.
   * **Result**: Displays context-specific metadata or details. For example, hovering over a file in File Explorer displays its size, file type, and modification date.
2. **Point and Click (Single Click)**:
   * **Action**: Moving the mouse pointer directly over an item and pressing the left mouse button once.
   * **Result**: Selects or highlights the item on the screen.
3. **Double-Click**:
   * **Action**: Quickly pressing and releasing the left mouse button twice in rapid succession.
   * **Result**: Opens the selected file, runs the application, or enters the folder.
4. **Drag and Drop**:
   * **Action**: Positioning the mouse pointer over an object, clicking and holding down the left mouse button, moving the mouse to a new position, and then releasing the button.
   * **Result**: Moves the selected item from its original location to a new location on the computer desktop or within folders.

## 3.5 Performing Basic File Operations

All data, software, and documents on a computer are organized inside files and folders.

### Files vs. Folders

* **File**:
  * The fundamental unit of data storage. Every piece of information (images, text documents, videos, music) is saved in a file.
  * **Naming Structure**: A file consists of a **filename** and a **file extension** separated by a dot (e.g., `notes.txt`). The extension (like `.txt`, `.jpg`, `.pdf`, `.mp3`) tells the operating system what type of data is in the file and which program is needed to open it.
* **Folder (Directory)**:
  * A physical or virtual storage container used to organize, group, and hold multiple files and other subfolders. Folders do not have file extensions.

### Basic File Operations

1. **Creating a File**:
   * Open a text editor (e.g., Notepad or Gedit).
   * Write your notes or text content.
   * Click on **File** -> **Save**.
   * Choose a storage location, enter a descriptive name with a `.txt` extension (e.g., `it_notes.txt`), and click **Save**.
2. **Creating a Folder**:
   * Navigate to the location where you want to create the folder (e.g., the 'Desktop' or 'Documents' directory).
   * Right-click on any empty space to open the context menu.
   * Hover over **New** and click on **Folder**.
   * Type a name for your folder (e.g., `Demo` or `NATIONAL CLASSES`) and press **Enter**.

### Keyboard Shortcuts for File Management

Keyboard shortcuts increase working efficiency by eliminating the need to navigate nested GUI menus.

| Keyboard Shortcut | Core Function | Description |
| :--- | :--- | :--- |
| **CTRL + S** | **Save** | Saves the active document or file changes. |
| **CTRL + A** | **Select All** | Selects all files inside a folder or all text inside a document. |
| **CTRL + C** | **Copy** | Copies the selected text or file to the system clipboard without removing it from the original location. |
| **CTRL + X** | **Cut** | Copies the selected text or file and deletes it from its original location, holding it in the clipboard. |
| **CTRL + V** | **Paste** | Places the copied or cut text or file at the active cursor or directory location. |
| **CTRL + Z** | **Undo** | Reverts or cancels the very last action performed. |
| **CTRL + Y** | **Redo** | Reapplies or cancels an undo command. |
| **CTRL + P** | **Print** | Opens the print dialog box to output the active document to a printer. |

## 3.6 Computer Care and Maintenance

Computers, laptops, and smartphones are delicate, expensive electronic devices. Setting up a regular care and maintenance routine extends the operational life of your hardware, prevents hardware degradation, and protects your critical information.

### Core Maintenance Tips for Electronic Devices

1. **Keyboard Protection**:
   * **Tip**: Never eat or drink food items directly over the keyboard.
   * **Why**: Food crumbs and sticky sugar residues can fall between keycaps, clogging key switches and damaging internal circuits.
   * **Cleaning**: Gently brush out dust and crumbs using a soft, dry brush or a small compressed-air duster.
2. **Screen Care**:
   * **Tip**: Wipe the monitor or phone screen gently with a clean, soft microfiber cloth.
   * **Why**: Normal cloths can scratch sensitive screens. Avoid using harsh household chemicals or splashing water directly onto the screen.
3. **Be Careful with Liquids**:
   * **Tip**: Keep glasses of water, cups of coffee, and liquid containers away from computers.
   * **Why**: Any liquid spilled over electronic circuits can cause immediate electrical short circuits, destroying motherboard components beyond repair.
4. **Careful Handling**:
   * **Tip**: Handle and carry laptops gently. Avoid dropping or banging devices against hard surfaces.
   * **Why**: Impacts can crack screens, break casings, and permanently ruin internal storage drives (especially Hard Disk Drives with moving parts).
5. **Keep the Device Cool**:
   * **Tip**: Ensure the computer's exhaust fan vents are completely uncovered. Avoid using laptops directly on soft beds, blankets, or pillows.
   * **Why**: Soft surfaces block air intake vents. When a CPU cannot ventilate, heat accumulates rapidly, leading to thermal throttling, hardware degradation, and potential fire hazards.
6. **Battery Management**:
   * **Tip**: Do not leave devices plugged into chargers continuously after reaching 100% battery capacity. Unplug chargers once fully charged.
   * **Why**: Constant charging generates excess heat and causes battery swelling, which significantly shortens overall battery life.
7. **Gentle Peripheral Connection**:
   * **Tip**: Gently plug in external USB drives, headphones, and power cables.
   * **Why**: Rough, forceful inserting or pulling damages the structural pins inside connection ports, rendering the ports unusable.
8. **Program Management**:
   * **Tip**: Avoid running too many heavy applications at the same time.
   * **Why**: Running excess background processes consumes system RAM and CPU cycles, making the operating system extremely slow, unresponsive, or prone to sudden crashes.

### Preparing a Maintenance Schedule

To keep computers running at maximum efficiency, implement a structured, tiered maintenance calendar:

```
[ MAINTENANCE SCHEDULE ]
   |
   +---> DAILY   : Inbox cleaning, save attachments
   +---> WEEKLY  : Keyboard/monitor dust, CPU wipe, external backup
   +---> MONTHLY : Transfer/clear photos, clean Downloads folder, uninstall apps
   +---> YEARLY  : Clean social/email contacts, OS update, renew Antivirus
```

#### A. Daily Maintenance
* **Clean up Email Inbox**: Delete promotional messages, archives, and unwanted emails daily to prevent inbox clutter.
* **Organize Attachments**: Download critical email attachments and save them immediately inside categorized, labeled directories.

#### B. Weekly Maintenance
* **Hardware Cleaning**: Clean the keyboard and wipe the monitor screen.
* **Dust CPU and Printer**: Dust off the external casings of the CPU cabinet and printer to prevent dust accumulation inside vents.
* **Data Backup**: Copy your critical files and project folders onto an external hard drive, USB storage, or secure cloud backup.

#### C. Monthly Maintenance
* **Mobile Storage Transfer**: Transfer photographs and videos from mobile devices to your computer's hard disk and delete them from the phone to free up phone storage.
* **Organize Photo Archives**: Place loose, transferred photos inside labeled albums or folders grouped by date/event.
* **Clean the 'Downloads' Folder**: Scan and delete temporary installation files (`.exe`, `.dmg`, `.msi`) and duplicate files from your Downloads directory.
* **Uninstall Unused Software**: Go to settings and uninstall programs, games, or applications that you no longer use.
* **Run Disk Cleanup**: Execute disk cleaner software to wipe system cache, internet cookies, and temporary log files, freeing up hard drive space.
* **Run a Full Virus Scan**: Initiate a complete system antivirus scan to find and isolate deep-system threats.

#### D. Yearly (Annual) Maintenance
* **Clean up Social Contacts**: Review and clean your contacts list on social media and professional networking accounts.
* **Clean up Email Contacts**: Delete inactive, obsolete, or duplicate entries from your email contact book.
* **Update the Operating System (OS)**: Install the latest feature updates and security patches for your operating system.
* **Renew Antivirus Software**: Check the expiration date of your antivirus subscription and renew it on time to maintain continuous system protection.

## 3.7 Computer Security and Privacy

Computer security and privacy are vital in today's interconnected digital landscape. If sensitive databases—such as school registries, bank records, or personal cloud storage—are compromised, it can result in identity theft, extreme financial losses, and privacy violations.

### Common Threats to a Computer

```
                   [ CYBER SECURITY THREATS ]
                               |
      +----------------+-------+-------+----------------+
      |                |               |                |
  [ THEFT ]       [ VIRUS ]     [ SCAMS / SPAM ]   [ ONLINE PREDATORS ]
  - Physical      - Worms       - Phishing Emails  - Fake Identities
  - Identity      - Trojans     - Lottery Fraud    - Cyberbullying
  - Piracy
```

1. **Theft**:
   * **Physical Theft**: The physical stealing of system hardware (laptops, desktop units, mobile devices) by an unauthorized person.
   * **Identity Theft**: When a hacker steals your personal information (name, Date of Birth, Social Security/Aadhaar number, banking credentials) to assume your identity. They can use this false identity to gain credit, withdraw bank funds, or carry out illegal activities in your name.
   * **Software Piracy**: The unauthorized copying, downloading, distribution, or commercial use of unlicensed software programs.

2. **Viruses (Malware)**:
   * **Definition**: Malicious, self-executing software programs written with the intent to damage system files, corrupt software, steal stored information, or degrade hardware performance.
   * **Worms**: A highly dangerous type of virus that automatically replicates itself. Once it infects a computer, it spreads across folders and networks independently without requiring human action, making it extremely difficult to detect and remove.
   * **Trojan Horse**: A malicious program that disguises itself as a useful, safe, or legitimate utility (like a free game or media player). Once downloaded and run by the user, it starts executing malicious tasks in the background, destroying files or leaking system passwords.

3. **Spam & Scams**:
   * **Spam**: Unsolicited junk emails sent in bulk by marketing companies or malicious actors to advertise products, clutter inboxes, or lure users into visiting unsafe websites.
   * **Internet Scams**: Fraudulent schemes designed to trick users into giving away money or personal details. 
     * *Example*: Emails stating you have won a massive lottery and requesting a small bank transfer fee to claim the prize. Once paid, the scammers disappear, and your banking credentials are stolen.

4. **Online Predators**:
   * **Definition**: Malicious individuals who use internet chatrooms, social networks, and online games to target, groom, and trap children or teenagers into inappropriate or dangerous relationships. They often assume fake online identities to bully, manipulate, or force victims into illegal actions.

### Data Protection and Security Measures

Implementing proactive security controls protects your digital assets and preserves data confidentiality.

1. **Use Strong, Complex Passwords**:
   * Set secure passwords to lock computer profiles and online accounts.
   * A password is hard to hack if it contains a minimum of 8 characters, comprising a mix of:
     * Uppercase letters (**A-Z**)
     * Lowercase letters (**a-z**)
     * Numbers (**0-9**)
     * Special characters (**@, #, $, %, &, *, !**)
   * *Avoid using simple, guessable words* like your name, pet's name, birthday, or `"123456"`.

2. **Install Antivirus Software and Firewalls**:
   * **Antivirus**: Active software that runs in the background to scan incoming files, identify signatures of known malware, and automatically quarantine or delete viruses before they infect system files.
   * **Firewall**: A digital security barrier that monitors all incoming and outgoing network traffic. It permits safe data packets and blocks unauthorized data transmissions, preventing hackers from establishing remote connections with your computer.

3. **Encrypt Critical Data**:
   * Encryption is the mathematical process of scrambing plaintext data into unreadable ciphertext.
   * Banks, government institutions, and corporations encrypt important customer and transaction records. 
   * This forces users to input a unique **decryption password or physical key** before starting the computer or opening the file, making intercepted data completely useless to hackers.

4. **Use Only Secure Websites**:
   * Provide sensitive financial details (like credit card numbers or banking passwords) only on secure web portals.
   * Verify a website's security by checking its browser address bar:
     * The website URL must begin with **`https://`** (Hypertext Transfer Protocol Secure), where the '**s**' stands for Secure. (Do not input data on `http://` sites).
     * A closed **padlock symbol** must be visible next to the URL.
